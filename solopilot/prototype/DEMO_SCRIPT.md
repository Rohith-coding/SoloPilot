## Recording Tips (Windows)

### Option 1: Xbox Game Bar (Built-in, easiest)
1. Open the prototype in Chrome/Edge. Make the window the right size.
2. Press **Win + G** to open Game Bar.
3. Click the **Capture** widget → **Start recording** (or press **Win + Alt + R**).
4. Record your demo. Narrate using your microphone.
5. Press **Win + Alt + R** again to stop.
6. Files are saved to `Videos\Captures`.

### Option 2: OBS Studio (Free, more control)
1. Download from [obsproject.com](https://obsproject.com).
2. Add a **Window Capture** source → select your browser.
3. Add an **Audio Input Capture** → select your mic.
4. Click **Start Recording**.
5. Files save to `Videos` by default.

### Trimming
- **Clipchamp** (built into Windows 11): Open the video, trim start/end, export.
- **CapCut** (free): More features, easy to use.

### Uploading to YouTube
1. Go to [studio.youtube.com](https://studio.youtube.com).
2. Click **Create** → **Upload video**.
3. Set visibility to **Unlisted** (only people with the link can watch).
4. Copy the link — that's your submission URL.
